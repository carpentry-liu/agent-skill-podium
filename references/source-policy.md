# Source and evidence policy

Use the strongest available source and keep a direct link to the exact page that supports the result.

## Evidence levels

| Level | Accept for placement? | Evidence |
| --- | --- | --- |
| A | Yes | Organizer-owned result page or official blog explicitly names the award and recipient. |
| B | Yes | Official competition platform result tab or announcement whose organizer identity is visible. |
| C | Conditional | Organizer-maintained GitHub repository or official social announcement. Prefer A or B; explain why stronger evidence is unavailable. |
| D | No | Participant README, portfolio, news roundup, search snippet, social repost, stars, likes, or community discussion. Use only as a lead. |

Two independent D-level sources do not become placement proof. If an official page links to a participant project, use the official page for placement and the project page only for title, team, summary, demo, or repository details.

## Search order

1. Organizer domain plus the exact event title and `winners`, `results`, `awards`, `获奖`, `结果`, or the local-language equivalent.
2. Official event or competition platform page.
3. Organizer's GitHub organization or official repository.
4. Project platforms to resolve an official project's canonical URL.

Use date filters for current requests. Compare the event date, result-announcement date, and page publication date; a recently edited page may describe an older event.

## Ranking boundaries

- `1st`, `2nd`, and `3rd` support numeric ranks.
- `Grand Prize`, `regional winner`, `best use of`, `category winner`, and `honorable mention` are award labels, not numeric ranks unless the organizer explicitly says otherwise.
- Finalists are not winners.
- A list's visual or DOM order is not a rank unless the page labels it as one.
- Do not compare winners across different tracks as if they shared one leaderboard.

## Conflicts and changes

Prefer the organizer's newest explicit correction. Keep the current fact in the dataset and mention the change in `verification_note`. If equally authoritative pages conflict and no correction is visible, do not choose silently: keep the disputed value unknown and report the conflict.
