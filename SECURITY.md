# Security policy

This repository is a static site and documentation-oriented Skill. It does not require API keys, user accounts, or a backend.

Please report a vulnerability through GitHub's private vulnerability reporting feature when it is available for this repository. If private reporting is unavailable, open a minimal public issue without secrets, exploit payloads, personal data, or sensitive infrastructure details and ask the maintainer for a private contact channel.

Do not submit credentials in competition data, project links, issues, fixtures, or pull requests.
